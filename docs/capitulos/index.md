# Capítulos

Cada capítulo es un pedido de Lúpulo Litoral en una etapa de su crecimiento. Tiene cinco partes:

1. **El llamado:** qué le pasa al cliente y qué pide.
2. **Núcleo:** los objetivos técnicos obligatorios.
3. **Misiones secundarias:** temas opcionales que suman.
4. **Tickets:** fallas provocadas (o sorpresa) resueltas como soporte N2.
5. **Entregable:** lo que queda para mostrarle a un cliente o en una entrevista.

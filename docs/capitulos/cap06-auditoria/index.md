# 6. Nos auditan

!!! note "Estado: pendiente · Plataforma: EVE-NG"
    Esta página muestra el plan. Se completa con el diseño, las decisiones y los tickets a medida que avanza el capítulo.

## El llamado

Una cadena de supermercados quiere vender Lúpulo Litoral en todo el Litoral. Antes manda a Carla, su auditora: ¿quién entra a los equipos de red y cómo queda registrado? ¿Hay backups de las configuraciones? ¿Qué pasa si un empleado se va? ¿Dónde están los logs? Martín reenvía el mail con un solo comentario: "Ayuda".

## Núcleo

- [ ] TACACS+ con perfiles de solo lectura y de administración.
- [ ] Usuario local de emergencia documentado.
- [ ] Syslog centralizado con NTP sincronizado.
- [ ] DNS interno.
- [ ] Hardening: banners, timeouts, servicios innecesarios apagados, SSH restringido a gestión.
- [ ] Backup automático de configuraciones.

## Misiones secundarias

- [ ] 802.1X / WPA2-Enterprise con RADIUS para el Wi-Fi del personal.
- [ ] Wazuh como SIEM liviano.
- [ ] Suricata en el pfSense de Gualeguaychú como IDS.

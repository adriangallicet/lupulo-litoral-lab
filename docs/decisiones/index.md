# Decisiones de arquitectura

Cada decisión de diseño que no sea obvia queda registrada en un ADR (*Architecture Decision Record*): qué situación obligó a decidir, qué se eligió, qué se descartó y qué consecuencias tiene. Sirven para que dentro de un año (o en una entrevista) se pueda explicar por qué la red es como es.
